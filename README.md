# Road Accident Risk Classification — Streamlit

## Files
- `kaggle_train.csv`: training dataset
- `train_model.py`: trains the model and saves `road_incident_risk_model.pkl`
- `app.py`: Streamlit prediction interface
- `requirements.txt`: Python packages for deployment

## Run locally
1. Install Python.
2. Open this folder in VS Code.
3. In the terminal run:
   ```bash
   pip install -r requirements.txt
   python train_model.py
   streamlit run app.py
   ```
4. Open the local URL printed by Streamlit (normally `http://localhost:8501`).

## Deploy on Streamlit Community Cloud
1. Create a GitHub repository and upload `app.py`, `train_model.py`, `requirements.txt`, `kaggle_train.csv`, and the generated `road_incident_risk_model.pkl`.
2. Open https://share.streamlit.io/ and sign in with GitHub.
3. Click **Create app**, select the repository and branch, and set the main file path to `app.py`.
4. Click **Deploy**. Streamlit will provide the public `*.streamlit.app` URL.

The saved model is generated by `train_model.py`; retrain it if you change the input features. Risk predictions are for educational use only, not real-world safety decisions.
